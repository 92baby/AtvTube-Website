Install it in three steps

  1. Get the file onto your device

    Download it in the device’s browser, or save it on a computer and copy it over with a USB drive. On Android TV, a file manager app helps you find it.

  2. Open it and allow the install

    Open the APK. When Android asks, allow installs from the app you opened it with, such as your browser or file manager.

  3. Tap Install, then open Atvtube

    When it finishes, Atvtube appears with your other apps.
